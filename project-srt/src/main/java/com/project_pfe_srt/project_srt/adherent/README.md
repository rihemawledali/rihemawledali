# Adherent Features

Purpose: self-service area for adherents.

Subfeatures:

- `profile`: profile, dashboard, password and personal data.
- `adhesion`: membership request and renewal.
- `convention`: convention catalog and adherent requests.
- `historique`: adherent financial history.
- `indemnite`: indemnity requests.
- `pret`: social loan requests.
- `offres`: assigned ticket/offer decisions.

Controllers keep the existing `/api/adherent/*` endpoint contracts.
